# DigBell

### A smarter way to manage bells.

DigBell is a Windows desktop application designed to help manage scheduled bell ringing from one place. It aims to make bell timing easier to organize and more consistent throughout the day.

## Download DigBell

**Get the latest stable release:**

➡️ **[Download DigBell for Windows](https://github.com/nduwayo-nathan/DigBell-Downloads/releases/latest)**

On the Releases page:

1. Open the latest stable release.
2. Under **Assets**, download the `DigBell_Setup_*.exe` installer.
3. Run the installer and follow the on-screen instructions.

> Download the installer from this official repository only.

## Installation

1. Download the latest DigBell Windows installer from [Releases](https://github.com/nduwayo-nathan/DigBell-Downloads/releases/latest).
2. Open the downloaded `.exe` file.
3. Follow the installation instructions.
4. Launch DigBell and configure your school bell schedule.

If Windows displays a security warning, verify that you downloaded the installer from this repository before deciding whether to continue.
